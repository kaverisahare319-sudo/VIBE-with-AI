# MockMate AI

MockMate AI is a premium SaaS platform designed for student Interview Readiness & Placement Preparation. The platform features an AI-powered Suite including ATS resume screening, coding assessments, communication/body-language diagnostics, group discussion simulations, and a placement readiness predictor.

## Features

- **Resume Analyzer & ATS Scanner**: Analyze resumes against key skills and ATS standards.
- **Career Roadmap Page**: Customized learning timelines based on desired roles.
- **Coding Assessment**: Simulated technical IDE with compilation, test case verification, and complexity analysis.
- **Communication & Body Language Analysis**: Analyzes speech mechanics and live emotions via webcam.
- **AI Mock Interview & GD Simulator**: Interactive audio mock interviews and multiplayer GD rooms with AI participants.
- **Placement Predictor**: Multi-dimensional scoring framework indicating company-wise readiness (TCS, Accenture, Product, etc.).

## Setup & Running

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Start Dev Server**:
   ```bash
   npm run dev
   ```
   This runs both the Express backend (port 5000) and the React/Vite frontend (port 5173).
